## ⚙️ How to Run the Code

Most of the files in this repository are standalone scripts. You can clone this repository and run the files using your local compilers or interpreters.

```bash
# Clone the repository
git clone https://github.com/pritam-das-coder/MyCodes.git
```
For C/C++: Use gcc or g++ to compile and run the .c or .cpp files.

For Python: Run the .py files using python3 filename.py.

For Java: Compile using javac filename.java and execute with java filename.
