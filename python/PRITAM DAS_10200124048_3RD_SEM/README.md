# 📝 Text Editor GUI in Python

A simple and efficient **Text Editor GUI** built using Python and Tkinter. This project demonstrates file handling, GUI design, and basic editor functionalities similar to a notepad application.

---

## 🚀 Features

* 📂 Open and edit text files
* 💾 Save and Save As functionality
* 🗂️ Multiple tabs (Tabbed interface)
* ✏️ Basic editing options (Cut, Copy, Paste)
* 🌙 Light/Dark mode toggle
* 📊 Status bar showing file path and editing status
* 🧭 Menu bar (File, Edit, View, Help)
* ⚠️ Error handling (e.g., missing icon)

---

## 🛠️ Technologies Used

* Python 3
* Tkinter (built-in GUI library)

